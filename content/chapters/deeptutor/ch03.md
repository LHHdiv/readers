> 读源码的第一原则：先跑起来，再谈理解。冷启动的调用链就是最好的导览图。

## 仓库地图：目录即架构

```
deeptutor/
├── main.py            # 入口
├── core/
│   ├── loader.py      # 文档加载与分块
│   ├── embedder.py    # 嵌入抽象
│   └── retriever.py   # 检索器
├── agent/
│   ├── loop.py        # 智能体循环
│   └── tools/         # 工具集
└── eval/              # 评估与回放
```

目录结构几乎就是架构图本身。这是挑选学习对象时最重要的信号。

## 一次冷启动的四个阶段

1. **加载配置**：`dev.yaml` 决定模型、存储与检索器；
2. **构建索引**：文档被解析、分块并写入向量库；
3. **装配智能体**：注册工具，绑定检索器；
4. **进入服务循环**：等待第一次提问。

## 动手：追一次启动

```bash
git clone https://github.com/example/deeptutor
cd deeptutor && uv sync
uv run python main.py --config dev.yaml
```

在四个阶段的入口各打一个断点，逐步放行，把经过的函数名抄在本讲笔记里。
